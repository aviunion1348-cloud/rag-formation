# Walkthrough film build scripts

These are the exact scripts that produced `docs/lear_agent/demo_video/lear_walkthrough_4k.mp4` and `lear_walkthrough_1080p.mp4`.

The film is a 3 min 37 s walkthrough of how the take-home brief is met. It is 3840×2160 at 24 fps (H.264 + AAC), with a voiceover, synthesized music and sound effects, and burned-in subtitles.

**None of this tooling is a project dependency.** Node, `@napi-rs/canvas`, numpy, scipy and `imageio-ffmpeg` are used only here, in throwaway environments under `/tmp`. They are not in `pyproject.toml`, and the product and its tests run without them.

## Files

| File | Role |
|---|---|
| `plan.py` | Narration text for the 7 scenes and the cue words. It times every scene to its voice clip and writes `plan.json`. |
| `walkthrough_plan.json` | The `plan.json` the film was rendered from: scene and cue times, and the 59 subtitles. |
| `walkthrough_data.json` | Every value the film draws, extracted from this repository's evidence: the redacted demo bundle, eval `run.json` files, bench JSON, generated docs, the requirements matrix and a scratch index. |
| `render.js` | Frame renderer (`@napi-rs/canvas`). It draws each frame from the plan and data and pipes raw RGBA to ffmpeg. It also writes the animation manifest. |
| `audio.py` | Soundtrack. It places the voice clips, synthesizes the music bed (pad, sub, kick, hats, arp, ducked under the voice) and puts 511 synthesized sound effects on the visual cues. It writes a 48 kHz stereo WAV. |

## What the counts mean

`walkthrough_animation_manifest.json` lists **3,322 timeline animations**. Each one is a single element with its own timed motion on the film's timeline:

- **data** (2,651): the element encodes a real value from the repository evidence. Its `src` field names the source.
- **text** (247): typography and subtitles.
- **decor** (424): decorative motion.

These figures count animated elements. They are not a measure of quality, and the film makes no claim beyond the repository's evidence: its heads-up display reads `offline baseline · NOT QUALIFYING` throughout.

## Rebuild

The scripts read and write fixed paths under `/tmp`:

- `/tmp/vo/n1_open.wav` … `/tmp/vo/n7_outro.wav`: voice clips;
- `/tmp/vfxdata/data.json`: copy of `walkthrough_data.json`;
- `/tmp/fonts/`: the fonts listed below;
- `/tmp/vfxbuild/`: plan, stills, manifest, soundtrack and video.

```bash
# throwaway tool environments (not project dependencies)
python3 -m venv /tmp/vfx && /tmp/vfx/bin/pip install numpy scipy imageio-ffmpeg
mkdir -p /tmp/vfxnode && (cd /tmp/vfxnode && npm install @napi-rs/canvas)
mkdir -p /tmp/vfxbuild /tmp/vfxdata && cp scripts/walkthrough/*.py scripts/walkthrough/render.js /tmp/vfxbuild/
cp scripts/walkthrough/walkthrough_data.json /tmp/vfxdata/data.json
FF=$(/tmp/vfx/bin/python -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())")

/tmp/vfx/bin/python /tmp/vfxbuild/plan.py                     # needs the 7 voice clips in /tmp/vo
SCALE=1 STILLS="31,57.5,90,165,204.4" node /tmp/vfxbuild/render.js   # QA stills at 1080p
SCALE=2 FFMPEG=$FF PRESET=ultrafast CRF=16 MAXRATE=80000k BUFSIZE=160000k \
  OUT=/tmp/vfxbuild/master_4k.mp4 node /tmp/vfxbuild/render.js        # 4K master, about 11 min on 2 vCPUs
/tmp/vfx/bin/python /tmp/vfxbuild/audio.py                    # soundtrack.wav
# trim soundtrack.wav to exactly 5206/24 s (10,412,000 samples) -> soundtrack_trim.wav, then:
$FF -i /tmp/vfxbuild/master_4k.mp4 -i /tmp/vfxbuild/soundtrack_trim.wav -map 0:v -map 1:a \
  -c:v libx264 -preset faster -tune animation -crf 20 -maxrate 2000k -bufsize 4000k -pix_fmt yuv420p \
  -c:a aac -b:a 160k -movflags +faststart lear_walkthrough_4k.mp4
$FF -i /tmp/vfxbuild/master_4k.mp4 -i /tmp/vfxbuild/soundtrack_trim.wav -map 0:v -map 1:a \
  -vf scale=1920:1080:flags=lanczos -c:v libx264 -preset medium -tune animation -crf 21 -maxrate 800k \
  -bufsize 1600k -pix_fmt yuv420p -c:a aac -b:a 160k -movflags +faststart lear_walkthrough_1080p.mp4
```

Two notes on the encode:

- Do not use `-shortest` for the final encode. With ffmpeg 7 it buffered raw 4K frames until the 3.9 GB sandbox ran out of memory. The audio is trimmed to the video length instead.
- Run the two encodes one after the other. A single `split` filter feeding both encoders also exhausted memory.

## Assets

- **Fonts** (all SIL Open Font License): Inter (static instances made with fontTools), Bebas Neue and JetBrains Mono. They were fetched from `google/fonts` and `JetBrains/JetBrainsMono`.
- **Voice:** text-to-speech of the narration in `plan.py`.
- **Music and sound effects:** generated by `audio.py`. No samples or third-party audio are used.
