#
# The core package is standard-library only and runs with no installation.

#
#   pypdf      — PDF text extraction (loaders.PDF). Without it, .pdf raises an

#                already parses word/document.xml from the zip container directly.
#
# Install into a virtualenv, not the system interpreter (PEP 668):
#   python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements-optional.txt
pypdf>=4.0,<6.0
